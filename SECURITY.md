# Security policy

## Supported version

Security fixes are applied to the latest release and the default branch.

## Reporting a vulnerability

Do not publish a security issue containing personal data, real identifiers,
third-party hashes, breach material, credentials or exploit evidence.

Use the repository's **Security > Report a vulnerability** option to open a
private security advisory. Describe the affected version, impact,
reproduction conditions and a minimal synthetic test case. Reports are
normally acknowledged within seven calendar days.

Requests to adapt the laboratory to real datasets or to identify individuals
are outside the project's scope and will not be accepted.
